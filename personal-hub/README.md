# Personal Hub

Προσωπικό, **modular** web app που τρέχει τοπικά στον υπολογιστή σου.
Ξεκινά με το module **Έξοδα** — καθημερινή καταγραφή, σάρωση αποδείξεων, πάγια
και ιστορικό ανά μήνα/έτος — και μεγαλώνει με όσα modules θελήσεις να προσθέσεις.

Όλα τα δεδομένα μένουν στον browser σου (IndexedDB). Δεν υπάρχει server, δεν
υπάρχει λογαριασμός, τίποτα δεν ανεβαίνει πουθενά.

---

## Εκκίνηση

**Προϋπόθεση:** Node.js **20.19+ ή 22.12+** (κατέβασε το «LTS» από
[nodejs.org](https://nodejs.org)). Έλεγξε με `node -v`.

```bash
cd personal-hub     # ΠΡΟΣΟΧΗ: μέσα στον φάκελο personal-hub, όχι στη ρίζα του repo
npm install         # κατεβάζει και στήνει και τα αρχεία του OCR (~25 MB, μία φορά)
npm run dev
```

Μετά **άνοιξε μόνος σου** τη διεύθυνση που τυπώνει το τερματικό:
<http://localhost:5180>. Ο server μένει ανοιχτός όσο τρέχει το `npm run dev`
(σταματάει με `Ctrl+C`).

Για «κανονική» έκδοση που τρέχει πιο γρήγορα:

```bash
npm start           # build + server, στο ίδιο http://localhost:5180
```

Ο φάκελος `dist/` είναι στατικός — μπορείς να τον βάλεις σε οποιονδήποτε
web server ή σε NAS. Για να το ανοίγεις και από το κινητό στο ίδιο δίκτυο:
`npm run preview -- --host`.

### Αν δεν τρέχει

| Τι βλέπεις | Τι φταίει |
|---|---|
| `npm: command not found` / `'npm' is not recognized` | Δεν υπάρχει Node.js. Εγκατέστησέ το από [nodejs.org](https://nodejs.org) και ξανάνοιξε το τερματικό. |
| `Η έκδοση του Node.js είναι παλιά…` | Παλιό Node. Κατέβασε την LTS έκδοση και ξανατρέξε `npm install`. |
| `Could not read package.json` / `Missing script: dev` | Είσαι σε λάθος φάκελο. Χρειάζεται `cd personal-hub` πρώτα. |
| `Cannot find module` ή λευκή σελίδα | Δεν έτρεξε το `npm install`. Τρέξ' το και ξαναδοκίμασε. |
| Λευκή σελίδα με διπλό κλικ στο `index.html` | Δεν ανοίγει έτσι — χρειάζεται `npm run dev` και μετά <http://localhost:5180>. |
| `Port 5180 is in use` | Το Vite διαλέγει μόνο του άλλη θύρα· δες ποια τυπώνει και άνοιξε εκείνη. |
| Η σάρωση απόδειξης «κολλάει» την πρώτη φορά | Φορτώνει τα μοντέλα OCR (~25 MB από τον δίσκο). Μόνο την πρώτη φορά. |

## Τι κάνει το module «Έξοδα»

### Καταγραφή
- Νέο έξοδο με ποσό, ημερομηνία, κατηγορία, κατάστημα, τρόπο πληρωμής, ΦΠΑ,
  ΑΦΜ, αριθμό παραστατικού και σημειώσεις.
- Δύο βασικοί τύποι: **Επαγγελματικά** και **Προσωπικά** — με ξεχωριστές
  κατηγορίες, ξεχωριστά σύνολα και ξεχωριστή παρακολούθηση ΦΠΑ.
- Αυτόματος υπολογισμός καθαρής αξίας και ΦΠΑ από το τελικό ποσό.

### Σάρωση αποδείξεων (OCR)
- Τραβάς φωτογραφία ή σύρεις αρχείο· η εφαρμογή διαβάζει την απόδειξη και
  συμπληρώνει **ποσό, ημερομηνία, επωνυμία, ΑΦΜ, αριθμό παραστατικού και ΦΠΑ**.
- Προτείνει και κατηγορία από την επωνυμία (πρατήρια, σούπερ μάρκετ,
  φαρμακεία, ΔΕΚΟ, λογισμικό, λογιστές…).
- Αν βρει ΑΦΜ, θεωρεί το παραστατικό επαγγελματικό και αλλάζει τύπο μόνο του.
- Δείχνει τα υπόλοιπα ποσά της απόδειξης ως κουμπιά, για διόρθωση με ένα κλικ,
  και το ακατέργαστο κείμενο που διάβασε.
- Η φωτογραφία αποθηκεύεται μαζί με το έξοδο.

**Τρέχει 100% τοπικά** (tesseract.js + WebAssembly, ελληνικά και αγγλικά). Δεν
χρειάζεται internet, δεν χρειάζεται API key, καμία απόδειξη δεν φεύγει από τον
υπολογιστή σου. Τα αρχεία γλώσσας αντιγράφονται στο `public/tesseract/` με το
`npm install` — ο φάκελος είναι στο `.gitignore`, οπότε δεν βαραίνει το repo.

Πρακτικές συμβουλές για καλύτερη ανάγνωση: ίσιωσε την απόδειξη, καλός φωτισμός,
όλο το χαρτί μέσα στο κάδρο. Πάντα ελέγχεις τα πεδία πριν αποθηκεύσεις.

### Πάγια έξοδα
- Ασφάλειες, ΕΝΦΙΑ, τέλη, συνδρομές, ενοίκιο — μηνιαία, ανά δίμηνο, τρίμηνο,
  εξάμηνο ή **ετήσια**.
- Οι εγγραφές δημιουργούνται **αυτόματα** όταν έρθει η ημερομηνία χρέωσης
  (και αναδρομικά για όσες χρεώσεις πέρασαν όσο δεν άνοιγες την εφαρμογή).
- Δείχνει ετήσιο κόστος και μέσο μηνιαίο, ώστε να συγκρίνεις πάγια μεταξύ τους.

### Ιστορικό & στατιστικά
- **Μήνας** (ανά ημέρα) · **Έτος** (ανά μήνα, με κλικ για zoom σε μήνα) ·
  **Σύνολο** (ανά έτος).
- Σύνολο, επαγγελματικά, προσωπικά, ΦΠΑ επαγγελματικών, με σύγκριση με την
  προηγούμενη περίοδο.
- Κατανομή επαγγελματικά/προσωπικά, κατάταξη ανά κατηγορία (γράφημα ή πίνακας)
  και κορυφαία καταστήματα.
- Προαιρετικός μηνιαίος προϋπολογισμός για τα προσωπικά.

### Δεδομένα
- **Εξαγωγή CSV** με ελληνικά headers και υποδιαστολή κόμμα — ανοίγει σωστά στο
  Excel και δίνεται έτοιμο στον λογιστή. Εξάγει και μόνο τα φιλτραρισμένα.
- **Αντίγραφο ασφαλείας JSON** και **εισαγωγή** (παραλείπει τα διπλότυπα).
- Κατηγορίες: μετονομασία, χρώμα, απόκρυψη, δικές σου προσθήκες.

## Προσθήκη νέου module

```bash
cp -r src/modules/_template src/modules/notes
```

1. Άλλαξε `id`, `name`, `description`, `icon` στο `src/modules/notes/index.ts`.
2. Γράψε τη σελίδα στο `Page.tsx`.
3. Δήλωσέ το στο `src/core/registry.ts`.

Η πλοήγηση, το URL (`#/notes`), η κάρτα στην αρχική και το mobile menu
προκύπτουν αυτόματα. Αν το module χρειάζεται δικά του δεδομένα, πρόσθεσε store
στο `SCHEMA` του `src/core/db.ts` και ανέβασε το `DB_VERSION` — δες το
`src/modules/expenses/store.tsx` ως πλήρες παράδειγμα.

## Δομή

```
src/
  core/       db (IndexedDB), registry των modules, router, θέμα, μορφοποίηση
  ui/         design system: Icon, Modal, Toast, StatTile, γραφήματα SVG
  modules/
    dashboard/    αρχική με σύνοψη
    expenses/     το module των εξόδων
      lib/        ocr, receiptParser, recurring, stats, transfer
      components/ φόρμα, λίστα, φίλτρα, στατιστικά, πάγια, ρυθμίσεις
    _template/    σκελετός για νέο module
scripts/
  setup-assets.mjs   αντιγράφει τα assets του OCR μετά το npm install
```

Χωρίς UI framework, χωρίς βιβλιοθήκη γραφημάτων: React + TypeScript + Vite,
CSS με design tokens (φωτεινό/σκούρο θέμα) και γραφήματα σε καθαρό SVG.
Η παλέτα των γραφημάτων είναι ελεγμένη για αχρωματοψία σε φωτεινό και σκούρο.

## Ιδιωτικότητα & αντίγραφα

Τα δεδομένα ζουν στο IndexedDB του συγκεκριμένου browser και προφίλ. Αυτό
σημαίνει:

- Αν καθαρίσεις τα δεδομένα ιστότοπου του browser, **χάνονται**.
- Άλλος browser ή άλλος υπολογιστής = άλλα δεδομένα.

Γι' αυτό: **Ρυθμίσεις → Αντίγραφο ασφαλείας (JSON)** τακτικά. (Οι φωτογραφίες
των αποδείξεων δεν μπαίνουν στο JSON λόγω μεγέθους — μένουν τοπικά.)
